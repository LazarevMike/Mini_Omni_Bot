# Contributing

Mini Omni Bot is a prototype, and feedback is welcome.

- **Report a problem or ask a question:** open an issue on the [Issues page](https://github.com/LazarevMike/Mini_Omni_Bot/issues). Name
  the page and step, or the board and the program's output.
- **Propose a change:** open a pull request. For a change to the code, run `tools/check_all.sh`
  first ([tools](tools/README.md)).
- **Write or draw for the guides:** follow the [style guide](docs/contributing/STYLE_GUIDE.md) and
  the [picture list](docs/contributing/PICTURES.md). Known gaps are in
  [known limitations](README.md#known-limitations).
