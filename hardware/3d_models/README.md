# 3D models

This folder is for the 3D models of Mini Omni Bot's printed parts. They are not in the repository
yet. It will hold a STEP file of each part for editing in any CAD program (FreeCAD is free), an STL
file of each part for printing, and a STEP file of the complete robot for checking fits.

File names follow the [planned scheme](../README.md#file-names-planned), for example
`P01_motor_plate_v1.step` and `P01_motor_plate_v1.stl`. Print settings will be published with the
models. Licence: CERN-OHL-P v2 ([../LICENSE](../LICENSE)).
