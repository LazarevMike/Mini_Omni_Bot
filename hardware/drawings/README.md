# Drawings

This folder is for the PDF technical drawings of Mini Omni Bot's parts. They are not in the
repository yet. It will hold one drawing per part, with every dimension and hole position, for
making a part by other means or checking a print, and assembly drawings.

File names follow the [planned scheme](../README.md#file-names-planned), for example
`P01_motor_plate_v1.pdf` for part P01. Licence: CERN-OHL-P v2 ([../LICENSE](../LICENSE)).
